# متجر رخيص — نسخة جاهزة للتجربة

1. افتح `index.html` لتجربة المتجر على الكمبيوتر.
2. قبل النشر، افتح `app.js` وابحث عن:
   const WHATSAPP="0128660329";
   واستبدله برقم واتساب المتجر بصيغة دولية بدون + أو مسافات.
3. الطلبات في هذه النسخة تُرسل للعميل إلى واتساب المتجر.
4. لوحة الإدارة تحفظ المنتجات على نفس الجهاز بواسطة LocalStorage.
5. للتشغيل كـ PWA/تطبيق قابل للتثبيت على الهاتف، ارفع الملفات على استضافة HTTPS؛ فتح الملف مباشرة قد لا يفعّل Service Worker.
6. هذه نسخة أولى حقيقية للتجربة وليست نظام مخزون/دفع مركزي متعدد الأجهزة. المرحلة التالية يمكن أن تضيف قاعدة بيانات، حساب مدير، صور حقيقية، شركة شحن، ودفع إلكتروني.
